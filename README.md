# WMAC 2027 website

Static site (no build step). Preview: `python3 -m http.server 8000` in this folder.

Deploy free: push this folder to GitHub and enable Pages (Settings → Pages), or drag it into Netlify / Cloudflare Pages.

To update: edit `index.html` (content), `styles.css`, `script.js`. Deadlines for the countdown live in `script.js` (`milestones`).
